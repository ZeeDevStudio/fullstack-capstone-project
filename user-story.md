# GiftLink - User Story Template

## Core Format
**As a** [type of user]  
**I want to** [perform some action / have a specific feature in GiftLink]  
**So that** [I can achieve a specific goal or value regarding recycling/sharing items]  

---

## Example User Story 1: Finding Free Items (Search & Filter)
**As a** user looking to recycle and find free household goods,  
**I want to** search for item listings by specific categories (e.g., furniture, electronics, kitchen appliances),  
**So that** I can quickly locate free items I need instead of purchasing new ones.  

### Acceptance Criteria
- A category selection filter must be visible on the main gift items page.
- Selecting a category must instantly filter the displayed listings to match that criteria.
- If no items exist in a category, a message stating "No items found in this category" must be displayed.

---

## Example User Story 2: Giving Away Household Items (Listing Creation)
**As a** donor looking to give away unwanted household goods,  
**I want to** create a new item listing with a title, description, image, and condition details,  
**So that** other community members can see the item and request to pick it up.

### Acceptance Criteria
- A functional "Add Item" form must be accessible to authenticated users.
- The form must validate that essential fields (Title, Description, Category) are filled before submission.
- Once submitted, the item must immediately appear in the public GiftLink browse registry.
